# Procesamiento de Lenguaje Natural — Magíster en Data Science UDD

Repositorio de trabajos seleccionados del ramo. El primer proyecto incluido estudia iniciativas populares del proceso constituyente de Chile de 2023 mediante técnicas de procesamiento de lenguaje natural.

## Contenido

- [`proyecto-final/`](proyecto-final/): notebook de la cuarta iteración, documentación y guía para obtener los datos por separado.

La carpeta local reúne muchos notebooks de clase, variantes de ejercicios, materiales docentes y resultados temporales. Esta publicación selecciona el proyecto final y omite presentaciones de clase, archivos duplicados, datos de entrada y resultados derivados.
